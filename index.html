What you can do

从文档到交互演示，一条完整链路。

01 / IMPORT

README 直接生成

适合开源发布、功能说明和课程内容。把已有 Markdown 按标题拆成演示页面。

02 / NAVIGATION

翻页与快捷键

支持上一页、下一页、目录导航与进度提示，也能使用键盘控制。

03 / THEMES

多主题风格

使用预置主题生成不同视觉风格，适合产品、技术、咨询等场景。

04 / DEPLOY

可分享的静态 HTML

生成结果无需部署服务即可离线打开，也可以上传到静态托管平台分享。

Get started

复制命令，开始你的第一场演示。

仅需 Git、Python 3.11+ 和 Make；不依赖 npm 构建过程。

Terminal · macOS / Linux
# 下载并进入生成器目录
git clone https://github.com/AIPMAndy/LivePPT.git
cd LivePPT/skills/public/LivePPT

# 从现成 README 生成 HTML
make build-from-readme README_INPUT=README.md OUTPUT=dist/readme-deck.html

# 浏览器打开生成结果
open dist/readme-deck.html

Windows 可运行 python scripts/build_from_readme.py README.md --output dist/readme-deck.html。不支持直接导出 .pptx，也不保证复杂 Markdown 布局无损还原。
